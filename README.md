# scoop-folio

The [Scoop](https://scoop.sh) bucket for [Folio](https://github.com/lulu-loopp/folio-terminal), a terminal that typesets formulas where a command prints them, with files previewed beside the prompt.

```powershell
scoop bucket add folio https://github.com/lulu-loopp/scoop-folio
scoop install folio
```

Update with `scoop update folio`.

The Explorer right-click entry ("Open in Folio") is switched on from inside Folio — the first-run card, or Settings ▸ General — not by Scoop. It keeps working across `scoop update`.
